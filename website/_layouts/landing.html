Ambient Code Platform

Orchestrate intelligent agentic sessions through Kubernetes-native microservices. Ship features, research, and analysis with AI agents that work while you sleep.

Get Started View on GitHub
$ make kind-up # cluster running at localhost:8080

Capabilities

▷

Agentic Sessions

Define a prompt, point at your repos, and let Claude Code execute. Batch or interactive, with real-time status via WebSocket.

⇄

Multi-Repo Support

Operate across multiple repositories simultaneously. Per-repo input/output configuration with branch and fork targeting.

⚙

Kubernetes Native

Custom Resources, an Operator, and Job-based execution. Sessions are CRs. The platform speaks Kubernetes end to end.

🔒

Multi-Tenant Isolation

Project-scoped namespaces with RBAC enforcement. User tokens flow through every API call. No elevated shortcuts.

⚡

Amber Background Agent

Automate fixes, refactoring, and test coverage through GitHub Issues. Label an issue, get a PR. No IDE required.

📈

Observability

Privacy-first Langfuse integration. Track token usage, costs, and model performance with full message redaction by default.
